# Twitch Streak Saver

A cross-platform Rust desktop app and Chromium extension for managing Twitch stream queues and tracking Channel Point Streaks.

## Quick start

Run the desktop app and choose **Set up browser extension**. For platform-specific installation and browser pairing, see [Setup](SETUP.md).
